🏈 Kodiaks Assistant GM

The Alberta Cup

Kodiaks Assistant GM is a personal fantasy football analytics application designed to help manage and analyze one private Yahoo Fantasy Football league.

Purpose

The application connects to Yahoo Fantasy Sports data to organize league rosters, transactions, player availability, standings, matchups and related fantasy football information.

The application is intended for personal use with a single private fantasy football league.

Data Use

Yahoo Fantasy Sports data is used to provide analysis and decision-support information for the league. The application does not sell or publicly redistribute league data.

Current status: Personal project in development.
